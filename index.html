Diseño adaptable: Aprenderás a crear páginas que se ven bien en cualquier dispositivo, ya sea móvil, tablet u ordenador. Usarás Flexbox, CSS Grid y media queries para que el contenido se reorganice según el tamaño de la pantalla.

Usabilidad y accesibilidad: Descubrirás cómo hacer interfaces intuitivas y accesibles para todas las personas. Aplicarás las heurísticas de Nielsen y las pautas WCAG: contraste de colores, textos alternativos, navegación con teclado y HTML semántico.

Prototipado y CSS ordenado: Aprenderás a planificar una web antes de programarla con guías de estilo, wireframes y prototipos en Figma. Además, organizarás tu código CSS de forma limpia con BEM y Sass, para que sea fácil de mantener.
