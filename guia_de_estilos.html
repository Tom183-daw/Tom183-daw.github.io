2. Tipografía

Tres fuentes, tres roles. Nunca mezcles los roles: Orbitron solo en títulos.

Orbitron

Títulos (H1, H2) · 700 / 900

Futurista y geométrica. Muy ancha: úsala en titulares cortos y evita párrafos.

Montserrat

Subtítulos (H3, H4), botones, etiquetas · 500-700

Sans geométrica muy legible; hace de puente entre Orbitron y el texto.

Aptos

Texto corrido, formularios · 400 / 600

Fuente de Microsoft, cómoda para leer párrafos largos.

Jerarquía

H1 · Orbitron 900 · 2.4remTítulo principal
H2 · Orbitron 700 · 1.7remTítulo de sección
H3 · Montserrat 700 · 1.3remSubtítulo de bloque
H4 · Montserrat 600 · 1.05remSubtítulo menor
Cuerpo · Aptos 400 · 1rem / 1.6Este es un texto de párrafo. Mantén líneas de 60-75 caracteres para leer cómodo.
Código · JetBrains Mono · .85remconst color = "#3D0262";

Nota sobre Aptos

Aptos no está en Google Fonts: solo se ve si el usuario la tiene instalada (Windows 11 / Microsoft 365). Por eso el stack incluye Segoe UI y system-ui como respaldo. Si necesitas que se vea igual para todos, usa @font-face con un archivo con licencia o cambia a Inter o Open Sans, muy parecidas.

Buenas prácticas

  • Un solo botón primario por vista; el lima, solo para la acción principal.
  • Orbitron con letter-spacing ligero y nunca en párrafos.
  • Foco visible siempre (anillo #C271F4).
  • No uses texto morado claro sobre fondos claros: mira la tabla de contraste.
